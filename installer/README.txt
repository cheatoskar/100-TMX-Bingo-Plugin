======================================================================
ENGLISH
======================================================================

You need the TrackMania ModLoader first:
https://tomashu.dev/software/tmloader/

INSTALL - with automatic updates (recommended)
  The ModLoader downloads the mod and every new version itself.
  You don't need this zip for it.
  1. Close the ModLoader completely (also the tray icon).
  2. Open this file with Notepad (paste it into the Explorer address bar):
       %LOCALAPPDATA%\TMLoader\config.yaml
  3. Add this line under "servers:" (two spaces in front, like the
     lines already there) and save:
       - 'https://cheatoskar.github.io/100-TMX-Bingo-Plugin/modloader/'
  4. Start the ModLoader, tick "100% TMX + Bingo", start the game.

INSTALL - the easy way
  1. Unzip this whole zip (right-click it, "Extract All...").
  2. Run 100TMX-Installer.exe from the unzipped folder.
  3. Open the ModLoader, tick "100% TMX + Bingo", start the game.

INSTALL - by hand, no .exe
  1. Unzip this zip.
  2. Open this folder (paste it into the Explorer address bar):
       %LOCALAPPDATA%\TMLoader\database\TmForever\products
  3. Copy the folder "100% TMX + Bingo" from the zip into it.
     If it is already there, let Windows merge the folders.
  4. Open the ModLoader, tick "100% TMX + Bingo", start the game.

FIRST START
  Press F9 in game -> Connection -> Connect, and approve the code on
  the website that opens (sign in with Discord).
  Then pick a bingo board on the Bingo tab.

UNINSTALL
  Run  100TMX-Installer.exe /uninstall
  or delete the folder "100% TMX + Bingo" from the products folder above.

VIRUS WARNING?
  The installer is not code-signed, so Windows may warn about it.
  It only copies the "100% TMX + Bingo" folder into the ModLoader -
  if you would rather not run it, use the "by hand" way above.
  The release page lists a SHA-256 for every file to compare with.

Full guide: https://github.com/cheatoskar/100-TMX-Bingo-Plugin#readme

DEUTSCH
======================================================================

Zuerst wird der TrackMania ModLoader benötigt:
https://tomashu.dev/software/tmloader/

INSTALLIEREN - mit automatischen Updates (empfohlen)
  Der ModLoader holt den Mod und jede neue Version selbst.
  Diese ZIP wird dafür nicht gebraucht.
  1. ModLoader ganz schließen (auch das Symbol im Infobereich).
  2. Diese Datei mit dem Editor öffnen (in die Adresszeile des
     Explorers einfügen):
       %LOCALAPPDATA%\TMLoader\config.yaml
  3. Diese Zeile unter "servers:" einfügen (zwei Leerzeichen davor,
     wie bei den Zeilen dort) und speichern:
       - 'https://cheatoskar.github.io/100-TMX-Bingo-Plugin/modloader/'
  4. ModLoader starten, "100% TMX + Bingo" anhaken, Spiel starten.

INSTALLIEREN - der einfache Weg
  1. Die ganze ZIP entpacken (Rechtsklick, "Alle extrahieren...").
  2. 100TMX-Installer.exe aus dem entpackten Ordner starten.
  3. ModLoader öffnen, "100% TMX + Bingo" anhaken, Spiel starten.

INSTALLIEREN - von Hand, ohne .exe
  1. Die ZIP entpacken.
  2. Diesen Ordner öffnen (in die Adresszeile des Explorers einfügen):
       %LOCALAPPDATA%\TMLoader\database\TmForever\products
  3. Den Ordner "100% TMX + Bingo" aus der ZIP dort hineinkopieren.
     Falls er schon existiert, die Ordner zusammenführen lassen.
  4. ModLoader öffnen, "100% TMX + Bingo" anhaken, Spiel starten.

ERSTER START
  Im Spiel F9 -> Connection -> Connect drücken und den Code auf der
  Webseite bestätigen, die sich öffnet (Anmeldung mit Discord).
  Danach im Bingo-Tab ein Board auswählen.

DEINSTALLIEREN
  100TMX-Installer.exe /uninstall  ausführen
  oder den Ordner "100% TMX + Bingo" im products-Ordner oben löschen.

VIRENWARNUNG?
  Der Installer ist nicht signiert, daher kann Windows warnen.
  Er kopiert nur den Ordner "100% TMX + Bingo" in den ModLoader -
  wer ihn nicht ausführen möchte, nimmt den Weg "von Hand" oben.
  Auf der Release-Seite steht zu jeder Datei ein SHA-256 zum Vergleichen.

Ausführliche Anleitung: https://github.com/cheatoskar/100-TMX-Bingo-Plugin#readme
